
**詳しい説明**

```
ここは赤提灯が揺れる、炭火焼きの焼き鳥屋さん。
網の上でジュージュー焼ける串を、ちょうどいい焼き加減のときにお客さんへ出そう。
うまく出せば「さんきゅう！」、生焼けや焦げを出すと「こらー！」。今日の売上はいくらになる？

■ 5種類の串を焼き分ける
・レバー、ねぎま、もも、つくね、手羽先
・串ごとに焼き時間が違う。レバーはすぐ焼けて、手羽先はじっくり
・串の上のメーターが金色になったら食べごろ

■ フリックでお客さんへ
・ちょうどいい串を上へフリックしてお客さんに出す
・焦げてしまった串は下へフリックで捨てればセーフ
・放っておくと炭になってミス。ミス5回で閉店
・売上が上がるほど焼けるのが速くなり、忙しくなる
・指ごとに串をつかめるので、両手の親指で同時に出せる

■ 毎回ちがうお客さん
・会社員、おじいさん、消防士、忍者まで、串を出すたびにお客さんが入れ替わる
・お客さんの反応と声で、焼き加減の良し悪しがすぐわかる

■ お祭り気分の焼き鳥屋
・藍色の暖簾、揺れる赤提灯、炭火の焼き台と立ちのぼる煙
・笛と太鼓のお囃子のBGM。売上が上がるとテンポアップ
・閉店すると「本日の売上」のレシートと称号（見習い〜伝説の焼き師）
・ベスト記録を保存。結果をシェアして友だちと競おう

■ そのほか
・日本語と英語に対応
・ログイン不要、オフラインでも遊べる
・無料（広告が表示されます）
```
